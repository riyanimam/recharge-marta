# Recharge MARTA — Frontend

Built with [Nuxt 3](https://nuxt.com/) and [Vue 3](https://vuejs.org/).

## Setup

```bash
pnpm install
```

## Development

Start the dev server at `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Build for production:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```

## Linting & Formatting

```bash
pnpm lint
pnpm format
```
